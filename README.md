## 📖 About This Project

CodeSnippet Manager is a **proprietary web application** designed and developed by **Mohamed Ghoul** to provide developers with an elegant solution for organizing and managing code snippets. This repository serves as a **showcase and documentation** of the project's features and capabilities.

> **Note:** This is a closed-source project. The code is not available for cloning, forking, or redistribution.

---

## ✨ Features

### 🎯 Core Functionality
- **🔐 Secure Authentication** - Google Sign-in powered by Firebase
- **💾 Smart Organization** - Advanced tagging and filtering system
- **🔍 Intelligent Search** - Context-aware snippet discovery with real-time results
- **⭐ Favorites System** - Quick access to your most-used code snippets
- **🌓 Dark Mode Support** - Beautiful light and dark themes with smooth transitions
- **📱 Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- **🔒 Privacy Control** - Choose between public or private snippet visibility

### 🛠️ Advanced Capabilities
- **50+ Language Support** - Syntax highlighting for JavaScript, Python, Java, C++, HTML, CSS, SQL, Bash, Go, Rust, Markdown, JSON, and more
- **⚡ Real-time Sync** - Instant updates across all your devices
- **📊 Code Analytics** - Automatic line, word, and character counting
- **📥 Export Functionality** - Download snippets in various formats
- **🏷️ Unlimited Tags** - Organize with custom categorization
- **🎨 Modern UI/UX** - Smooth animations powered by Framer Motion
- **💫 Rich Code Editor** - Full-featured editor with multiple views and tabs

## 🖼️ Interface Preview

### Welcome Experience
Clean, modern landing page with animated gradients and smooth transitions that guide new users through the platform's capabilities.

### Dashboard
Intuitive snippet management interface with grid view, advanced filters, and instant search. The sidebar provides quick access to all organizational tools.

### Code Editor
Full-featured editing experience with syntax highlighting, line numbers, code statistics, and one-click copying. Supports public/private visibility controls.

### Detail View
Comprehensive snippet viewer with tabbed interface showing code, details, and tags. Includes download, share, and favorite functionality.

## 🌟 Feature Highlights

### Advanced Search & Filtering
The platform offers multiple ways to find your snippets instantly:
- **Full-text search** across titles, descriptions, and code content
- **Language filtering** for all 50+ supported programming languages
- **Tag-based organization** with multi-select capability
- **Favorites filtering** for quick access to starred items
- **Real-time results** that update as you type

### Privacy & Security
Built with security as a priority:
- **Firebase Authentication** ensures secure user management
- **Private snippets** are only visible to you
- **Public snippets** can be shared with controlled visibility
- **Session management** with automatic token refresh
- **Encrypted data** transmission and storage

### Professional Code Display
Every snippet is presented beautifully:
- **Syntax highlighting** with carefully selected color schemes
- **Line numbers** for easy reference
- **Copy to clipboard** with visual feedback
- **Download functionality** with proper file extensions
- **Mobile-optimized** code viewing experience

## 🏗️ Architecture Overview

The application follows a modern component-based architecture:

- **Authentication Layer** - Firebase-based secure login system
- **State Management** - Custom hooks for efficient data handling
- **Component Library** - Reusable UI components with consistent styling
- **API Integration** - RESTful backend communication with token-based auth
- **Responsive Design** - Mobile-first approach with Tailwind CSS
- **Animation System** - Framer Motion for smooth, performant animations
